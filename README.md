# IELTS Word Lab

Daily IELTS vocabulary practice with Bangla meanings.

- Daily words for IELTS Reading, organised by the topics that come up in Cambridge-style passages, with definitions, example sentences and paraphrase synonyms
- High-frequency IELTS Listening words, grouped by the situations where they appear
- Topic vocabulary for Listening Part 4 lectures (questions 31-40)
- Spelling practice: see the Bangla meaning, write the English word
- Dictation: hear the word, type it
- Typing practice with IELTS words (speed and accuracy)
- Spaced repetition reviews, daily goal, streak, activity calendar and weak-word list

Progress is saved in your own browser. It is a single `index.html` file, hosted with GitHub Pages.
